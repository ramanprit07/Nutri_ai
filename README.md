# 🥗 Nutri AI

Nutri AI is an AI-powered nutrition application that helps users make healthier food choices based on their personal information and dietary preferences.

## 🚀 Features

* Personalized nutrition recommendations
* AI-based food and health insights
* Simple and user-friendly interface
* Predictive analysis using Machine Learning
* Data visualization for better understanding

## 🛠️ Technologies

* Python
* Pandas & NumPy
* Scikit-learn
* Matplotlib / Plotly
* Streamlit
* Jupyter Notebook

## 📊 Machine Learning

The application uses a **Logistic Regression predictive model** to analyze user and nutrition-related data and generate predictions.

## ▶️ Run the App

```bash
https://nutriai.streamlit.app/
```

## 🎯 Goal

To provide users with a simple AI-based tool for making informed and personalized nutrition decisions.
